# amonet

This is an exploit chain for Fire HD 6 / 7 (2014) (4th gen / `ariel` / `aston` / `KFARWI` / `KFASWI`).

It contains a MediaTek preloader exploit and a LittleKernel bootloader exploit. Read more about it [here](https://blog.r0rt1z2.com/hacking-a-2014-tablet-in-2024.html#hacking-a-2014-tablet-in-2024).

Instructions on how to use it can be found in [this XDA thread](https://xdaforums.com/t/unlock-root-twrp-unbrick-fire-hd7-hd6-ariel.4679761/). I take no responsibility for any damage caused by using this.
